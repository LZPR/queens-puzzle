# 皇后 Queens

**打开即玩的皇后推理小游戏。** 每行、每列、每个色块各放一只皇后，皇后之间不能相邻。
4×4–16×16 十五种尺寸，每盘保证唯一解。

原生 ES 模块 + 一个零依赖静态服务器，没有构建、没有依赖、没有后端。
所有东西都在浏览器里跑，进度与战绩存在本机 `localStorage`。

---

## 它有什么

- **一盘一题，唯一解**——出题器现场生成，按「尺寸 + 试推深度 + 开局卡壳」打出难易分，
  六档目标难度（不限 / 容易 / 中等 / 较难 / 困难 / 极难）。
- **逐步提示**——从「这一格只能填这儿」一路讲到「先假设这里，三步之后矛盾」。
  还有两个减少体力活的辅助：自动标 ×、唯一位置提示。
- **不怕推歪**——撤销 / 重做 / 记录点（存下这一刻，推乱了一点就回来）；
  只剩皇后没标时，提示行会换成「补齐」一键收尾。
- **挑战模式**——限时、限步、标错扣命，也能把提示 / 撤销 / 记录点全部收起来，
  按「限时 × 难度」记排行榜。
- **每日挑战**——一天一盘，只跟日期有关；换设备、刷新多少回都是同一盘。五挡各挑各的。
- **战绩与分享**——每局留一张棋盘缩略图和一个分享码，`QNS1-...` 发给朋友就能开同一局。
- **外观可换**——色块图案 / 叉 / 皇后 / 命数四种画法，点击 / 背景 / 棋盘滤镜三样动效，
  共七类，靠抽奖解锁。

## 快速开始

```bash
# 方式一（Windows）：双击
启动局域网游戏.bat

# 方式二（任意系统）
python serve.py            # 默认 8080，被占用自动往后找
npm start                  # 同上，只是包了一层
```

打开终端里给出的地址即可。手机同一局域网内也能开（`serve.py` 就是为了这个）。

> **不要直接双击 `index.html`。** 应用是 ES 模块，`file://` 下浏览器会拦掉模块加载。
> 用任何静态服务器都行，只要走 http。

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 单击一格 | 打 ×（再点一下擦掉） |
| 同一格快速点两下 | 放皇后（再双击拿走） |
| 按住拖动 | 连涂一片 ×（可设为「按行列对齐」） |
| 顶栏回旋箭头 | 新的一局：尺寸、难度、挑战都在这儿挑 |
| 顶栏信息条 | 点任意一段打开「本局信息」 |
| 顶栏奖杯 / 调色盘 / 下载 | 战绩 · 外观 · 载入朋友的分享码 |

键盘：`X` 标叉，`Q` / `Enter` 放皇后，`Z` 撤销，`Shift+Z` / `Ctrl+Y` 重做，
`S` 记录点，`Shift+S` 清空记录点，`H` 提示，`N` 新局，`Esc` 关浮层。

## 项目结构

```
index.html          骨架：顶栏 / 棋盘 / 信息条 / 工具栏 + 浮层挂载点
serve.py            局域网静态服务器（零依赖）
src/styles/         唯一样式入口 all.css（顺序都在 @import 里，responsive.css 最后）
src/js/
  engine/           出题 · 难度 · 提示 三套引擎（经典脚本，浏览器与 Node 双端可用）
  looks/            外观插件：七类画法与数据，无依赖，最底层
  core/             基础设施：状态、存档、计时、浮层基座
  game/             棋局逻辑：规则、棋盘、分享码、缩略图
  ui/               渲染与共用件；ui/panels/ 下一个文件一个浮层
  app/              流程编排：动作、撤销栈、出题换盘、每日挑战
  events.js         指针 / 键盘 / 全局监听
  main.js           启动
docs/               难度与提示的调研报告、实施计划
tools/              端到端回归、引擎测试、截图与调参脚本
```

依赖方向是单向的：`looks ← core ← game ← ui ← app`。

## 测试

```bash
python serve.py --no-open      # 先起服务（测试脚本会开无头浏览器连它）
npm test                       # 全量端到端回归
node tools/test-engine.mjs     # 出题引擎
node tools/test-hint.mjs       # 提示引擎
```

`tools/check-*.mjs` 是按功能分的针对性回归（挑战 / 每日 / 战绩 / 外观 / 动效 / 步数…），
改哪块跑哪个，文件名对得上。
